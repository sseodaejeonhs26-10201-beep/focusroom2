# focus-room

집중을 도와주는 타이머 앱, **몰입의 방**입니다. HTML·CSS·JavaScript만으로 동작하며 별도 빌드가 필요 없습니다.

## 캐릭터 꾸미기

- **나만의 친구 꾸미기**에서 모리(토끼), 나비(고양이), 두리(곰), 루루(여우)를 무료로 선택합니다.
- 털색 6종, 표정 3종, 의상 색 4종을 무료로 바꿀 수 있습니다. 기본 털색은 동물마다 다릅니다.
- **작은 상점 → 캐릭터 의상**에서 집중 포인트로 목도리·왕관·안경·리본·니트를 구매합니다. 구매하면 바로 착용하고, 다시 누르면 벗습니다.
- 왕관과 리본은 함께 착용할 수 없습니다. 나머지 의상은 함께 착용하며, 구매한 의상은 모든 캐릭터가 공유합니다.
- **방 꾸미기**에서 화분·액자·조명을 구매하고 배치합니다.
- 외형·의상·포인트·기록은 현재 브라우저에 저장됩니다. 기존 버전의 포인트와 구매 내역도 유지합니다. 다른 기기나 브라우저에는 자동으로 공유되지 않습니다.

## 확인 및 배포

`index.html`을 브라우저로 열거나 저장소 루트를 정적 서버로 실행합니다. 계산 및 저장 데이터 호환성 검사는 Node.js에서 `node --test tests/core.test.js`로 실행합니다.

Vercel에서 Application Preset은 **Other**, Root Directory는 **./**, Build Command는 비워 둡니다. GitHub 연동 프로젝트의 운영 브랜치가 `main`이면 변경을 `main`에 병합할 때 자동 배포됩니다.
